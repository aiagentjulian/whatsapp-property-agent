# Pearlmont — Base Pricing

## Purpose

Canonical reference for original/base pricing structure before current rebate/package application.

This file is not the source for the latest effective customer price. For current rebate and package mechanics, use `sales-package.md` together with this file.

## Pricing model

The commercial structure should be understood as:

```text
Original / Base Price
+ applicable car-park premium
+ applicable upgrade / accessory components
= SPA / selling structure in the developer pricing reference

Then:

Current rebate / package
= separate dynamic commercial layer
```

Do not overwrite base pricing when a rebate changes.

## Car-park premiums

Project pricing materials show car-park premiums of:

- RM15k
- RM20k
- RM30k

The exact premium depends on unit/category/configuration. Do not apply a generic premium without the corresponding unit schedule.

## Other components shown in SPA pricing structure

Project Brief states SPA price may include:

- unit base price
- car-park premium
- extra motorcycle bay: RM5k where applicable
- extra utility: RM8k where applicable
- upgrading package worth RM10k

The extra motorcycle bay / utility allocation is shown as applicable only to units with 1 car park in the pricing material.

## Upgrading package reference

The RM10k upgrading package includes project-material references to:

- concealed air-conditioning piping with ceiling for living area and master bedroom
- Bedroom 2 and Bedroom 3 fan point / fan hook upgrades

## Customer-facing price behaviour

If the customer asks a simple question such as "how much?", do not default to quoting the full base-price matrix.

Customer-facing opening price should normally use the latest effective post-rebate "from" price from `sales-package.md` because that is the commercially relevant hook.

Use this file when the customer asks for:

- original price
- base price
- SPA price structure
- why different units have different prices
- floor/view/car-park premium explanation
- rebate calculation detail

## Accuracy rule

A unit-specific final figure should only be given when both are known:

1. the correct current unit/base-price structure
2. the correct current rebate/package eligibility

If either is uncertain, present an indicative range and say the latest exact unit/package should be confirmed.
