## Source Priority Rule
For date-sensitive project milestones:
1. Use the newest official FAQ / current developer material.
2. If a newer official sales circular or project update is added later, it should override this file.

## Customer-Facing Language
Preferred wording:
- "Expected Q4 2029" or equivalent.
- Avoid saying completion is guaranteed on an exact date unless an official contractual date is specifically available and the system is instructed to use it.

## Construction / Handover Claims
Do not infer:
- exact vacant-possession date,
- exact key-collection date,
- guaranteed early completion,
- guaranteed construction speed,
- exact completion month,
unless later official knowledge explicitly supports it.

Completion timing is factual support, not a sales guarantee. If a prospect's purchase decision depends heavily on timing, communicate the current expected period accurately and move toward confirmation / viewing rather than overpromising.
