# Pearlmont — Unit and Layout

## Purpose

Canonical factual knowledge for Phase 1 unit configuration, orientation, internal space, specifications and layout-related questions.

Primary source: `2026.09.21_PearlMont Phase 1_FAQ-update.pdf`.

Secondary source: `SkyWorld Pearlmont Project Brief - V4 FULL.pdf` for additional layout explanation where consistent with the FAQ.

## Standard unit

All Phase 1 residential units use the same main unit type:

- Type A
- Built-up: 900 sq.ft.
- 3 bedrooms
- 2 bathrooms
- Balcony
- Total Phase 1 units of this type: 1,846

- Master bedroom: 143.4 sq.ft.
- Bedroom 1: 117.4 sq.ft.
- Bedroom 2: 103.3 sq.ft.

- Bath 2: 35.0 sq.ft.

## Layout characteristics described in project materials

- Entrance foyer creates privacy so the living/dining area is not directly exposed from outside
- Kitchen is integrated into the modern open-plan living concept
- Project Brief describes an approximately 4m kitchen that can potentially be enclosed with a sliding door
- All three bedrooms are described as able to fit a queen-sized bed
- Master bedroom is described as sizeable enough to accommodate a walk-in wardrobe concept
- Bedrooms have outward-facing windows / natural daylight
- Bedroom 2 and Bedroom 3 are described as having two windows to support airflow
- Internal design is described as efficient with no long internal corridor
- Small storage area is included in the layout concept

Treat these as developer/project-material descriptions, not independently measured guarantees beyond the official plan.

## Renovation caution

Because the project uses PPVC, do not tell customers that any wall can be hacked or modified.

Project materials distinguish hackable and non-hackable walls and direct purchasers to the Home Owner Manual for embedded services. Any structural/renovation question that requires certainty should be confirmed against the latest owner/manual or developer guidance.
