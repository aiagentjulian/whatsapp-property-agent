# Pearlmont — Orientation and View

## Purpose

Use this file when a customer asks about tower orientation, unit facing, podium view, sea view, Plot 2 / pylon facing, blocked or unblocked views, or floor bands associated with those categories.

Do not treat a broad facing category as a guarantee of a precise visual outcome. Exact unit availability and final view should be confirmed against the latest unit chart / sales system.

---

## Commercial Category Mapping

Commercial sales-package and pricing documents also group units into categories such as:

- Garden Unit
- Podium Blocked
- Podium Unblocked
- Plot 2 / Pylon
- Plot 2
- Sea View

These category names are important because they can affect:

- base price
- carpark allocation
- current rebate package

Do not answer a commercial price question from orientation alone. Retrieve `pricing.md` and `sales-package.md` as well.

---

## Blocked vs Unblocked Podium

The current FAQ distinguishes podium-facing units by floor band:

- lower floors: blocked-view category
- higher floors: unblocked-view category

The exact floor threshold differs by block / commercial package and should be checked against the latest current package or unit chart.

Do not generalize that every podium-facing unit has the same view quality.

---

## Sea View

Sea-facing categories are present in Block 1C and Block 1D according to the FAQ / project materials.

Do not promise a permanent unobstructed sea view unless the exact unit and latest surrounding-development information support that statement.

Use “sea-facing” or “sea-view category” when that is what the project documentation supports.

---

## Plot 2 / Pylon

Block 1B includes categories facing Plot 2 and, on lower floors, Plot 2 & Pylon.

The FAQ separately states that Block 1B is approximately 36 m from the high-tension cable, against a stated minimum requirement of 20 m in the project material.

If the customer asks specifically about the pylon / cable, retrieve `risks-and-sensitive-faq.md` rather than turning the topic into a selling point.

---

## Agent Guidance

When a customer asks “which facing is better?” do not answer with a universal ranking.

First understand what matters to them, for example:

- view
- budget
- lower effective price
- carpark count
- morning / afternoon sun preference
- privacy
- floor height

Then use the factual categories in this file together with current pricing and package knowledge.

The later USP / Buyer Fit layer may provide positioning guidance, but this file remains factual only.
