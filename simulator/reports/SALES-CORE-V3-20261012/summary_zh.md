# Sales Core V3 配对评估摘要

## 结论

**建议暂不接入生产，也不要替换默认 V2。** V3 在本次 10 组盲评中与 V2 各胜 5 组，没有显示稳定优势。V3 对需求相关性和提问质量略好，但销售判断、重复控制和自然度评分较低；价格、投资回报和明显户型不匹配等场景中，V2 更早说明限制或及时结束。保留 V3 作为可选实验实现，修正重复追问、无法兑现的后续承诺和不必要的长对话后，再做新一轮评估。

## 实验范围与运行方式

- 使用同一 `gpt-6-luna`、`high` 推理设置，10 个场景分别运行 V2 与 V3，再由盲评模型逐组比较。
- 顾客模拟器持有隐藏人物设定，并根据对话动态回应；Agent 不会收到隐藏设定。完整对话、逐组判断和 token 记录见本目录中的 `SCV3-*.pair.json`、`aggregate.json` 与 `aggregate.md`。
- 总计 504 次已留存模型调用、942,022 输入 token、338,894 输出 token；已留存调用延迟合计 3,977 秒。V2 对话平均 6.7 个顾客回合，V3 平均 8.0 个。
- 按 GPT-6 Luna 标准短上下文 token 价格估算，已留存调用费用约 **US$0.2473**。**这不是完整账单：**早期恢复运行时，一个 V3 五回合部分尝试和三次未完成 API 响应在用量持久化修复前被覆盖，无法恢复其 token 使用量；实际实验成本高于该留存记录估算，差额未知。
- 同一运营入口的 fake-transport dry run 完成 10/10 组、90 次模拟模型角色调用，未产生计费 API 请求。实验未调用 CRM、SQLite、WhatsApp、实时库存、日历或人工客服通道。

## 逐组结果

| 场景 | V2 / V3 顾客回合 | 盲评胜者 | 主要观察 |
|---|---:|---|---|
| 家庭自住 | 8 / 10 | V3 | V3 对日常费用和周末看房需求衔接较好；重复总结，并暗示会稍后跟进。 |
| 首次置业、尚未明确优先项 | 10 / 10 | V3 | V3 的预算引导更温和；重复承诺提供后续估算。 |
| 预算与价格 | 4 / 7 | V2 | V2 开始即说明没有核实价格；V3 先承诺查询，之后才澄清不能联系销售团队。 |
| 租金回报 | 8 / 9 | V2 | V2 更明确地区分缺少证据与收益判断；V3 多次承诺索取资料。 |
| 四房硬性需求 | 2 / 7 | V2 | V2 很快说明项目只有三房并确认不匹配；V3 多聊数轮才结束。 |
| 地点与通勤 | 8 / 10 | V3 | 两者都避免编造通勤时间；V3 在地址是否为住宅地点上仍有较多来回。 |
| 洪水、安全与基础设施 | 8 / 9 | V2 | V2 给出有边界的 FAQ 信息，并较早说明无法联系项目团队；V3 先承诺索取资料，后撤回。 |
| 犹豫、低意向 | 7 / 6 | V2 | 两者均尊重暂不跟进；V2 更早直接回答浏览问题。 |
| 需求变化与回访问题 | 10 / 10 | V3 | V3 区分已知的设施按次收费与未知的会所入场费；但出现连续重复回复。 |
| 高意向但不喜欢被催 | 2 / 2 | V3 | 两者都没有声称预约已确认；V3 更明确说明需团队确认且不会持续催促。 |

## 实现与限制

V3 被 `SALES_CORE_VERSION=v3` 显式启用，未设置时仍默认走 V2。V3 在每轮先做结构化策略分析，再生成客户回复；复用现有知识检索与回复校验。SalesGPT 的 contextual analysis / knowledge selection 思路有参考价值，但其固定阶段流程与旧版 LangChain 工具链不符合当前运行方式，因此没有移植其依赖或销售阶段框架。

这 10 组仅是描述性样本，不能证明统计显著差异。模拟客户在若干场景中较配合、耐心且愿意继续对话；盲评也不能替代知识库逐条事实核验，尤其买家隐藏事实不等同于项目资料来源。报告中的费用是留存调用的模型价格估算，不是账户账单，并且已知有未留存用量。所有预约、团队联系和后续跟进内容都是对话输出，实验没有实际执行这些动作。

## 建议

保留 V2 为默认。V3 暂不接入 WhatsApp 生产路径；优先修正：

1. 首次回复避免承诺无法实际执行的联系、查询或稍后跟进。
2. 对明确硬性条件不匹配的客户尽早结束，不要继续资格询问。
3. 压缩未解决事项的重复回顾，防止同一轮重复回复。
4. 对“可用知识”“推断”与“需人工/团队确认”保持清晰区分。

之后用同一运营入口再次做 fake-transport dry run，并用新一批场景复测，再考虑是否接入。
