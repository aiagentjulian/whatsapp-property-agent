# Loop 11 — Appointment Setter Validation

## 结论

使用 Loop 10 六张冻结 persona，针对当前简化版 Sales Brain 完成六组真实 SalesAgent 对话。测试 45 项通过，六组都先用真实 Sales Lab 入口完成 fake-transport dry run。共 15 次真实 API 调用，输入 52,170、输出 20,203、合计 **72,373 tokens**。没有修改代码或 Sales Brain。

客户真实同意安排看房并正确触发 `APPOINTMENT_HANDOFF`：**1/6（Perai 通勤自住）**。三组对话中出现看房邀请，但所有邀请都没有自然提供 Weekdays / Weekends 选择；只有 Perai 一组推进到明确同意和 Handoff。没有把 Agent 的邀请算成客户同意，也没有声称任何日期或预约已确认。

## 检查

- 对话整体简洁，未出现问卷式预算/贷款资料收集；Perai 首轮追问具体工作区域，对方婉拒后 Agent 正常转向日常配套。
- 首购和家庭客户在看房前被带入房间尺寸、家具摆放和平面图核实，销售进程停在资料跟进。
- 三种 persona 收到看房邀请（家庭、Perai、长期持有）；Perai 对话中有两次邀请表达。邀请均未包含 Weekdays / Weekends 选择。
- Perai 在明确同意后，SalesAgent 输出 `APPOINTMENT_HANDOFF`，说明交由销售员联系并注明尚未预约，符合交接边界。

结果：当前版本在尊重低意向客户方面表现自然，但 Appointment Setter 验证仅部分通过；六组只有一组完成客户同意和 Handoff。按本轮要求，本报告只记录结果，不改 Brain 或添加规则。
