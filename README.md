# WhatsApp Property Agent

A lightweight AI property sales agent project.

- `/brain` contains the agent behaviour and sales logic.
- `/knowledge` will contain project-specific property knowledge.
- `/skills` will contain agent action/skill definitions.
- `/data/lead` will contain lead runtime/state data.
- `/simulator` will be used to test the agent before WhatsApp integration.
- `/app` will contain the runtime application later.

Core sales journey: `UNDERSTAND → QUALIFY → POSITION → HANDLE → INTENT → CLOSE`
